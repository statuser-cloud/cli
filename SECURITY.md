# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**[Report a vulnerability](https://github.com/statuser-cloud/cli/security/advisories/new)**
(Security → Advisories → Report a vulnerability). Do not open a public issue.

This covers the `statuser` package. Include the version, the steps to
reproduce and what an attacker gains.

Issues in the Statuser API itself can be reported the same way — they reach
the same team.

## Supported versions

Fixes go into the latest release. Update with `npm install -g statuser@latest`;
`npx -y statuser` always runs the latest one.
